# OpenReel Tutorials

OpenReel includes four in-product Chinese tutorial blueprints: a noir trailer, a product commercial, an ink-painting poetry film, and a mini documentary.

Open **Tutorials** in the workspace header, choose a project, review its steps and acceptance checklist, then place the blueprint on the current canvas. A blueprint creates titled and connected nodes with editable prompts. It never starts an Ark job, spends credits, or stores an API key.

Before generating, users should obtain administrator-approved access, replace the sample subject with authorized material, review model and cost settings, start with Lite/Fast previews, and verify successful assets on the timeline before export.
