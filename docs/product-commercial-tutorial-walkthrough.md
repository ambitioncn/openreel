# Beginner Walkthrough: Make a 15-Second Product Ad

This walkthrough describes the locally implemented OpenReel beginner flow as of 2026-09-16. It is written for a first-time user. The changes must still be deployed before they appear on the public website.

## Before you start

Prepare one clear product photo in PNG, JPEG, or WebP format. Use an image you own or have permission to use. Ask an adult to help review rights declarations or any paid-generation confirmation.

## 1. Join OpenReel

1. Open OpenReel.
2. Choose **English**.
3. Choose **Create account**.
4. Enter your email and a password of at least eight characters.
5. Choose **Create account** again.
6. Wait for the workspace to open.

You are finished with this part when the top bar shows OpenReel and a project name.

## 2. Open or create the correct project

1. Open **Projects**.
2. Choose an existing project, or choose **New project**.
3. If you make a new one, enter a name and choose **Create blank draft**.
4. Check the project name beside OpenReel in the top bar.

The tutorial always uses the current project shown there.

## 3. Start the tutorial

1. Open **Tutorials**.
2. Choose **15-second premium product ad**.
3. Read the orange explanation. The checklist only records progress; it does not perform or verify work.
4. Check the no-cost readiness message for image and video tools.
5. Choose **1 · Add blueprint to this project**.

OpenReel opens Advanced Canvas and creates five editable nodes: one script, one product image, and three video shots. Adding the blueprint does not run a model or spend allowance. If the blueprint already exists, the same button opens it instead of creating duplicates.

## 4. Replace the sample product

1. Select **Three-shot ad script**.
2. In **Content**, replace the sample with your product and three shots.
3. Select **Product hero image** and describe your product.
4. Edit **Hero reveal**, **Material close-up**, and **Final product hold**.

For image and video nodes, **Prompt** follows **Content** until you deliberately type a different Prompt. The Prompt box is the text that generation will use.

## 5. Continue in Create

1. Return to **Tutorials** and reopen the same tutorial.
2. Choose **2 · Continue in Create**.
3. Confirm that OpenReel selected:
   - **Continue the current project**;
   - **Paste existing script**;
   - **Product showcase**;
   - **About 15 seconds**.
4. Review the copied three-shot plan.
5. Choose **Create script and storyboard**.

This action uses the configured planning model and may record model usage. It does not begin image or video generation. The product-ad planning contract requires three shots of five seconds each.

## 6. Review the storyboard

1. Read all three shots.
2. Check that each duration is **5 seconds** and the total is **15 seconds**.
3. Use **Move up**, **Move down**, **Duplicate**, **Delete**, or **Add 5-second shot** if the structure needs editing.
4. Put the brand, price, and CTA in the final shot's text.
5. Choose **Save script and storyboard**.

Saving does not call a paid model.

## 7. Add an optional reference image

You can upload the image directly on the Tutorial page or in **Create → Asset library**.

1. Open **Asset library**.
2. Choose **Upload asset** and select your product photo.
3. Choose the uploaded image so its card says **Selected**.
4. Choose **Bind to all shots**.
5. In Step 4, choose **Use a reference image for person/product consistency**.
6. Select the reference and choose **Object only**.
7. Complete the rights declarations truthfully.

Uploading and binding do not call a model.

## 8. Add text cards

1. Make sure the text for every shot is saved.
2. Choose **Create text cards from every shot’s text**.
3. Check that all three safe-area text cards are selected.

These cards place the saved shot text inside the final video. **Project title** and **Publishing copy** are platform metadata and are not burned into the video.

## 9. Review cost and generate

1. Choose **Fast** for a draft or **High quality** for a final attempt.
2. Choose **Get cost estimate**.
3. Read the generation and quality-review amounts.
4. Stop if the shot count, duration, models, rights, or cost is wrong.
5. Check the confirmation box only when everything is correct.
6. Choose **Confirm and generate**.

This is the step that can start paid provider work. OpenReel shows generation, quality, retry, and redo states separately. A failed-shot redo requires a new quote and confirmation.

## 10. Review and download

1. Open Step 5 after the job says the render is ready and quality passed.
2. Play the complete video.
3. Check the product, three-shot order, 15-second duration, text, audio, and 9:16 framing.
4. Choose **Download final MP4**.

When a qualified commercial MP4 already exists, Download uses that file directly. It does not send it through the incompatible local preview re-render path.

## 11. Finish the tutorial checklist

Return to **Tutorials** and tick only the steps you actually completed. The boxes remember progress; they still do not run or verify the work.

## Recovery tips

- **Blueprint already exists:** choose **Open existing blueprint**.
- **No planning model:** the Create submission explains that planning is unavailable; no media generation starts.
- **No reference in the generation selector:** select the uploaded image in Asset library and choose **Bind to all shots**.
- **Wrong duration:** make three shots of five seconds each and save again.
- **Generation failed:** read the plain-language status. A retry or failed-shot redo may cost more and requires confirmation.
- **A final MP4 is visible:** use **Download final MP4** instead of creating another preview render.
